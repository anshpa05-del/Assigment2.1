Step 1: Create the index.html File
Create a new file named index.html in your project folder, and paste the following code into it. This code satisfies all requirements: standard document structure, the title "My First Webpage", one main heading, three subheadings, HTML comments, and proper indentation.

HTML
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <!-- Setting the page title as required -->
    <title>My First Webpage</title>
</head>
<body>

    <!-- Main Heading (H1) -->
    <h1>Welcome to My First Webpage</h1>

    <!-- Subheading 1 (H2) -->
    <h2>About This Page</h2>
    
    <!-- Subheading 2 (H3) -->
    <h3>My Learning Journey</h3>

    <!-- Subheading 3 (H4) -->
    <h4>Future Goals</h4>

    <p>This is a simple paragraph added to demonstrate proper HTML structure.</p>

</body>
</html>
Step 2: Verify by Opening in a Browser
Save your index.html file.

Open it in your web browser (you can use the Live Server extension from Assignment 1.2, or simply double-click the file to open it in Chrome, Safari, or Edge).

Check that the title tab displays "My First Webpage" and that all headings (<h1> through <h4>) render correctly.
